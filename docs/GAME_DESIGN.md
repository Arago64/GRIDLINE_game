# GRIDLINE — Mini Game Design Document (Prototype v0.1)

**Жанр:** 2D math / logic puzzle.  **Платформа:** браузер, offline.  **Стиль:** hand-drawn monochrome, технический блокнот, top-down grid.  **Движок:** отсутствует (HTML Canvas + JavaScript).

## Игровая идея
Соединить станцию A с подстанцией B линией электропередачи с минимальной стоимостью. Игрок свободно ставит опоры на разрешённых клетках сетки, соединяя их прямыми проводами. Карта включает высоты, дорогую землю, лес, воду и запрещённые зоны. Короткий маршрут не всегда самый дешёвый.

## Основной игровой цикл
Выбрать тип опоры → навести курсор и проверить пролёт → разместить опору → повторить → завершить соединение с B → сравнить итоговую стоимость с оптимизатором → переиграть для лучшего результата.

## Механика
- Три опоры: низкая (дешёвая), средняя, высокая (дорогая, но больше допустимый пролёт и зазор над землёй).
- Лес и частная собственность повышают цену размещения; пересечение частных участков проводом тоже стоит денег.
- Вода и запретные зоны не допускают установку опор, но могут быть пересечены проводом при достаточном зазоре.
- Допустимость пролёта определяется расстоянием, высотой опор, высотой клеток на отрезке и условной моделью провеса.
- Рейтинг: 3 звезды при стоимости до 115% от дискретного оптимума, 2 до 145%, иначе 1.

## Техническая задача
Оптимизация суммы стоимости опор, земли и проводов на дискретной карте при геометрических ограничениях. Опорный алгоритм: Дейкстра на графе возможных состояний, который использует идентичную игровую функцию проверки сегмента. Это позволяет сравнивать человеческие решения с проверяемым эталоном в рамках текущей модели.

## Объём прототипа
22 уровня, 6 типов покрытия/особенностей, 3 опоры, undo/restart, подсказка оптимизатора, прогресс по уровням, минималистичная векторная графика без внешних ресурсов. Следующие версии: редактор уровней, новые типы опор, независимые ветви сети, процедурная генерация и тесты баланса.

**Ограничение:** технические параметры умышленно игровые, не предназначены для реальных расчётов ЛЭП.
